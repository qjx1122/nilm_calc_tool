分路侧设备联动

ℹ 两侧都是离线文件（csv_file）时共用节拍钟（倍速一致、严格同步）并可按公共时间段播放；其它组合各自按自身配置同时启动，「公共时间段」不生效。
公共时间段＝两侧文件时标的交集；起始/结束都留空＝整段。
分路侧是一份完全独立的配置，落盘到 configs/branch_runtime.json，落盘/导出目录与总线侧相同（同一个 CSV 文件，按 source_id 区分：0 总线 / 1 分路）。 本页右列集中配置分路侧的数据源 / 量纲口径 / 列映射；窗长 / 事件阈值 / 负荷辨识参数在「分路侧」分组对应子界面改。

总线侧 数据源

「保存总线侧配置」保存上方数据源 + 量纲口径 + 列映射到 configs/runtime.json（在原文件基础上只更新这些键，其它配置不变）；「启动数据源」只按当前输入播放，不写配置文件。
勾选后（默认开启）：软件重启时自动把上次运行落盘的曲线 / 事件 / 负荷辨识事件（CSV）和最后一次电气量结果（output/last_result.json，两侧共用、按 source_id 分键）读回各子界面；最新电气量卡片、频谱等显示的是上次运行结束时的值。
启用分路侧后，这里的「启动 / 暂停 / 停止 / 加载上次数据」同时作用于两侧。
「加载上次数据」：不播放时，从 output/realtime、output/events、output/nilm 的 CSV 读回最近 history_hours 内本侧（source_id）的曲线点、事件与负荷辨识事件，供各曲线 / 事件页直接查看；重新启动播放后会被新数据覆盖。

分路侧 数据源

ℹ 两侧都是离线文件：联动启动时分路侧倍速随总线侧。
「保存分路侧配置」同时保存右列的数据源 / 量纲口径 / 列映射与上方联动参数；总线侧「启动数据源」会带起分路侧，这里的「单独启动」只启动分路侧。

总线侧 导出指定时间段的原始数据

只从总线侧当前配置的离线数据源 CSV 中，把指定时间段内的原始采样行按原样重新写到 output/raw_<起>_<止>_src0.csv（末尾追加 source_id=0 列），与另一侧的导出无关联；导出文件可直接再作为离线数据源播放。时间按本侧播放时间轴判断（含「自定义播放时间」）。

分路侧 导出指定时间段的原始数据

只从分路侧当前配置的离线数据源 CSV 中，把指定时间段内的原始采样行按原样重新写到 output/raw_<起>_<止>_src1.csv（末尾追加 source_id=1 列），与另一侧的导出无关联；导出文件可直接再作为离线数据源播放。时间按本侧播放时间轴判断（含「自定义播放时间」）。

总线侧 量纲与口径

分路侧 量纲与口径 独立于总线侧，随「保存分路侧配置」保存

总线侧 离线文件列映射 csv_file / csv_tail 取列规则，随「保存总线侧配置」一起保存

启用后只播放有映射关系的列：未映射的通道按 0 处理并在数据源状态中提示；保存后对下次启动/下一块数据生效。两侧列映射互不影响。
